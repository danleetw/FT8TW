網頁無法直接讀取你電腦裡的設定檔。兩種做法：上傳命令列版 ai_console.py backup 產生的 zip，或直接選取設定檔（例如 ~/.claude/settings.json、CLAUDE.md、~/.codex/config.toml）。

登入憑證檔（.credentials.json、auth.json、oauth_creds.json 等）一律不收。單一備份上限約 200 KB，單檔超過 64 KB 會略過。
